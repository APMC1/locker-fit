# Amazon Associates UK — application copy

Apply at: https://affiliate-program.amazon.co.uk/signup

Use the live GitHub Pages URL as the website. Amazon requires original public content, not a coming-soon page.

Put your legal name, personal email, tax interview and payout details only on Amazon’s private application. Do not add them to the public imprint. The live site uses GitHub Issues for contact and does not publish a home address.

UK help on the 180-day window: once you apply you have 180 days to refer a sale; Amazon says it evaluates the application once you have referred three qualifying sales. Personal orders do not qualify. Official topic: https://affiliate-program.amazon.co.uk/help/node/topic/G7MJTPEP9NC3YKMG

Required disclosure on every page with links (already in the HTML):

> As an Amazon Associate I earn from qualifying purchases.

Do **not** bid on “amazon” or misspellings. Do **not** put Special Links in unsolicited email.
